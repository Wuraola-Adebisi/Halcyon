# Halcyon Studio

A premium fictional architecture and interior design studio website built entirely with HTML and CSS. No frameworks. No JavaScript. Just considered design and clean code.

## About
Halcyon Studio is a concept website for a fictional high-end European architecture and interior design firm based in Oslo, Norway. The project was built to demonstrate advanced HTML and CSS skills across a large, multi-page, real-world brief — the kind of site a serious client would actually commission.

This is my first multi-page project and my most ambitious to date. It pushed me to think beyond single sections and consider how design, navigation, and user experience flow across an entire site. It also taught me patience — particularly around working with client-supplied images and finding CSS solutions that respect the integrity of the assets rather than fighting them.

## Pages
- **Home** — Hero image grid, selected work, services, philosophy, press strip
- **Work** — Full project grid with filter row and individual project links
- **Project Pages** — Six individual project pages, each with a split hero, info strip, description, and image gallery
- **Studio** — Philosophy, team, awards, and CTA
- **Contact** — Split layout with studio details and full enquiry form

## Built With
- HTML5
- CSS3
- Google Fonts — Cormorant Garamond, Inter
- CSS Custom Properties
- CSS Grid & Flexbox
- CSS Transitions & Hover Effects

## Features
- 10 fully linked HTML pages
- Multi-image hero grid on homepage
- Split layout project hero pages
- Contained image gallery — designed around client-supplied image constraints
- Sticky filter row on work page
- Previous / Next page navigation across all pages
- Project chain navigation across all 6 project pages
- Fully responsive across desktop, tablet, and mobile
- Contact form with fieldset grouping
- Consistent design system across all pages via a single shared CSS file

## CSS Techniques Used
- `CSS Grid` — homepage hero grid, project layouts, gallery, awards split
- `CSS Flexbox` — navigation, footer, info strips, form groups
- `object-fit: cover` with `object-position: center top`
- `aspect-ratio` — uniform image containers
- `position: sticky` — filter row on work page
- `columns` — philosophy text on about page
- `clamp()` — fluid typography throughout
- `fieldset` and `legend` — contact form grouping
- `appearance: none` — custom select styling
- `::before` and `::after` pseudo-elements
- `writing-mode: vertical-rl` — vertical text element
- CSS custom properties throughout — single source of truth for all colours and spacing

## What I Learned
This project taught me two things above everything else — patience and standards.

Patience, because multi-page sites require you to think systemically. A change in one place ripples across ten files. A design decision made on page one has consequences on page six. You cannot rush that kind of thinking.

Standards because working with client-supplied images — fixed resolution, varied proportions, real constraints — forced me to find CSS solutions that respected the assets rather than broke them. The easy answer is always to stretch and crop. The right answer takes longer.
